Install

Sideload the signed APK. It updates over older Nijatva Contacts builds signed with the same key.

1 — Download

Grab the latest APK from the releases page.

2 — Allow install

When Android asks, allow your browser or file manager to install unknown apps.

3 — Grant contacts

Android will ask for contacts access; the app cannot show your list without it.

Prefer a cable? One command:

adb install -r Nijatva_Contacts_v1.2.apk

Privacy is a permission, not a promise

The only network permission exists for one optional feature. If you never sign in to Zoho, the app makes no network calls at all.
